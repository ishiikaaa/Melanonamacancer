# Melanonamacancer
# 🧠 Melanoma Cancer Detection using XAI

This project implements an AI-based system to detect melanoma (a type of skin cancer) using deep learning models and Explainable AI (XAI) techniques. It features a mobile app for real-time classification and visual explanation.

## 📌 Features

- ✅ Classifies skin lesions as **benign or malignant**
- 🧠 Uses **ViT, ResNet-18, EfficientNet, and VGG-16** models
- 🌈 **LIME** and **Grad-CAM** for interpretability
